# WINBOX Site

Projet Next.js 14 App Router avec Tailwind CSS et internationalisation FR/AR.

## Démarrage

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm start
```

## Variables d'environnement

Créer `.env.local` avec les clés suivantes :

```
NEXT_PUBLIC_GA4=G-XXXXXXXXXX
NEXT_PUBLIC_META_PIXEL=XXXXXXXXXXXXXXX
RESEND_API_KEY=...
```
