# Yassine Raha — Conversion Studio Site

Futuristic one-page marketing site built to convert founders, entrepreneurs, and hospitality brands.

## Features
- Premium hero with smart personalization and embedded A/B testing.
- AI Copilot brief generator and ROI calculator with instant results.
- Services, portfolio, before/after transformations, testimonials, and conversion-focused contact form.
- Accessibility-first: keyboard navigation, ARIA labels, reduced-motion support, high contrast.
- PWA ready: manifest, service worker, offline fallback, lazy-loaded analytics module.
- Privacy-first cookie banner, schema markup, and SEO essentials.

## Development
Open `index.html` in a browser or serve via a static host. Update `assets/js/realtime.js` with production analytics when ready.
